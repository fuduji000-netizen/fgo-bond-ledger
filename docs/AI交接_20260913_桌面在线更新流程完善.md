# AI交接：桌面在线更新流程完善

日期：2026-09-13

## 本次实际修改

- 将桌面端更新流程拆分为“检测 → 下载 → 用户确认重启安装”。发现新版本后先下载；下载完成后可选择“重启并安装”，也可选择在下次正常退出时安装。
- 更新对话框现在显示当前版本、发布说明、下载百分比、已下载/总大小和下载速度；检测、下载与启动安装失败分别显示对应原因。
- 修复未打包开发环境中 `electron-updater` 返回 `null` 后，手动检测窗口会一直停在“正在检查”的问题；现在会明确说明当前运行方式不支持在线更新。
- 更新源配置支持 `channel`，默认 `latest`；仍只接受 HTTPS 地址。更新按钮会显示当前版本与是否配置更新源的提示。
- 新增 `scripts/generate-update-manifest.mjs`。`npm run dist:win` 现在会在完成 NSIS 构建后生成带安装包 SHA-512、文件大小和版本的 `release/latest.yml`，使通用 HTTPS 更新源具有完整元数据。
- 应用版本已由 `0.1.0` 升至 `0.1.1`。
- 更新了 `README.md` 的发布步骤与更新源配置说明。
