# AI 交接：BBC 礼装模板直接导入（2026-09-13）

## 本次修改

已将“制作 BBC 礼装模板”的输出方式改为**直接导入 BBchannel 的礼装资产目录**，不再让用户选择普通导出目录。

1. 账本现在单独保存 BBC 启动 `.cmd` 的路径：
   - 在模板制作器打开时读取该路径；
   - 若未设置、文件已不存在，或原先只设置了 `.exe`，制作器会显示提示，并提供“**获取 BBC 启动 CMD**”按钮；
   - 文件选择框只允许选择 `.cmd`；选择后会保存其绝对路径。若此前未设置 BBchannel 启动程序，也会将该 `.cmd` 作为原有 BBchannel 启动入口。
2. 模板导入目录严格按所选 `.cmd` 的**所在目录**推导：
   ```text
   <CMD 所在目录>\assets\assist\assist_equip\<模板名>.png
   <CMD 所在目录>\assets\assist\equip_check\<模板名>_1.png
   <CMD 所在目录>\assets\assist\equip_check\<模板名>_0.png
   ```
   其中后两张仅在用户同时提供满破、未满破游戏截图时生成。
3. 模板制作器主操作已改名为“**导入到 BBC 礼装目录**”。在 CMD 已确认后，界面会显示将要直接导入的 BBC 根目录；CMD 未确认时，导入按钮不可用。
4. 保留旧版兼容：若用户过去在 BBchannel 启动路径中选择的本身就是 `.cmd`，模板制作器可直接将其作为 BBC 根目录来源，无需重复选择。
5. 没有读取、写入或解析 `scripts_settings.json`，没有读取账号、设备连接或其他 BBC 配置正文；本次实现只保存账本自身的桌面路径设置，并在用户点击导入后写入上述两类 PNG 礼装资产文件。

## 未完成项 / 使用方式

- 本次没有替用户选择本机 BBC 的启动 `.cmd`，也没有向 `E:\BBchannel\BBchannel` 写入模板文件。实际使用时，在账本中打开“制作 BBC 礼装模板”后，先点击“获取 BBC 启动 CMD”选择 BBC 根目录内的 `.cmd`，制作完成后点击“导入到 BBC 礼装目录”即可写入对应资产目录。
