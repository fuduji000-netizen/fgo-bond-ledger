# 2026-09-11 交接文档：牵绊阶段规则与占星茶壶库存整合

## 已完成任务

### 1. 牵绊阶段自动升级规则

**需求**：Lv.0-Lv.9 达到上限自动跳级，Lv.10 及以后停留当前等级等待手动升级。

**实现**：
- `src/calculator.js` 的 `applyBattles` 函数：
  - Lv.0-Lv.9：进度填满后 `level += 1; progress = 0;` 自动跨阶段，不写入 `awaitingUnlock`。
  - Lv.10 及以后：进度填满后 `progress = requirement; awaitingUnlock = true;` 停留当前等级并提示。
  - 提示内容："已达到 Lv.X 上限；请在游戏内开启后，将牵绊等级手动改为 Lv.Y"。

**存档兼容**：
- `normalizeState` 修正 Lv.16 满绊不会被降级回 Lv.15。
- Lv.10-Lv.15 若 `progress === 0 && awaitingUnlock === true`，降级至前一阶段并填满进度。

### 2. 占星茶壶库存管理

**需求**：茶壶按库存数量优先用于前 N 场翻倍，记入战斗时整队共享一次消耗，不按五个从者重复扣。

**实现**：
- `src/calculator.js` 新增函数：
  - `normalizeTeaPotCount(raw)`：标准化为非负整数。
  - `calculateBattlePlan({ remaining, normalPerBattle, teaPotPerBattle, teaPotCount })`：
    - 茶壶优先填满前 N 场（每场 200%）。
    - 库存用尽后按普通场（每场 100%）。
    - 返回 `{ totalBattles, teaPotBattles, normalBattles, bondsFromTeaPot, bondsFromNormal }`。
  - `calculateSlot` 同时保留 `perBattleNormal` 与 `perBattleTeaPot`。
  - `applyBattles` 返回 `teaPotBattlesApplied`。

- `src/app.js` 的 `recordBattles` 函数：
  - 计算 `teaPotBattlesForRecord = Math.min(count, getActiveTeaPotCount())`。
  - 所有五个本方从者按相同的 `teaPotBattlesForRecord` 调用 `applyBattles`，避免重复扣减。
  - 循环完成后仅扣一次：`state.teaPotCount = Math.max(0, 当前库存 - teaPotBattlesForRecord)`。
  - 若没有任何可记入的本方从者（空编队或全部已达上限且停止记入），不扣茶壶库存。
  - 日志显示："占星茶壶：消耗 X 个，剩余 Y 个"。

**界面**：
- 保留 `#tea-pot-enabled` 复选框（决定茶壶是否参与计算）。
- 保留 `#tea-pot-count` 数量输入框（填写库存）。
- 结果卡显示："单场（普通）：100 点"、"单场（茶壶）：200 点"、"所需战斗：4 场（茶壶 2 场 + 普通 2 场）"。
- 顶部编队总牵绊显示："全队单场（普通）：500 点"、"全队单场（茶壶）：1000 点"。
