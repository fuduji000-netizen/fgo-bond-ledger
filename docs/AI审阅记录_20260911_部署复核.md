# 2026-09-11：Cost 与持有羁绊礼装图标修复部署复核

## 反馈与判定

用户截图中的编队显示为 `Cost 102 / 115`，用户确认应为 `114`。截图第一位为冠位从者：其本体 Cost 为 `16`，已保存但旧界面隐藏的常规礼装 Cost 为 `12`。旧逻辑错误地把冠位从者的常规礼装从 Cost 计算中排除，故总计少了 `12`。

正确规则如下：

- 非好友从者：从者本体 Cost 加一张常规礼装 Cost。
- 冠位从者：除上述常规礼装外，还有两张冠位专用礼装；这两张专用礼装不计 Cost。
- 好友位：从者与所有礼装均不计入我方编队 Cost。

因此，该截图对应的正确结果是 `102 + 12 = 114`。

用户同时反馈“持有羁绊礼装”中的图标显示不正确。原因是该列表误用了编队方形缩略图的下半部裁切样式。列表现已改为居中完整展示礼装图像；编队中的方形缩略图仍保留原有裁切效果。

## 已实现的修复

- `src/calculator.js`：常规礼装不再因从者是冠位而被排除出 Cost；好友位仍始终返回零 Cost。
- `src/app.js`：冠位从者显示一张常规礼装格和两张冠位专用礼装格，并提示其不同的 Cost 规则。
- `src/recommendation.js`：牵绊最大化礼装推荐将冠位从者按一张计 Cost 的常规礼装和两张不计 Cost 的专用礼装处理；好友常规礼装也不占用我方 Cost。
- `src/catalog.js`：同步缓存缺少礼装 Cost、图标或名称时回填内置快照字段，避免不完整缓存造成图标或 Cost 错误。
- `styles.css`：持有礼装清单和礼装选择器改用完整图标展示样式。
